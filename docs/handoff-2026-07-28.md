# Handoff — 2026-07-28

Read this before touching compression, savings reporting, or the release
pipeline. It records what changed, what is measured, what is still open, and
the traps that will otherwise cost you an afternoon each.

## The pattern worth knowing

Almost nothing found in this pass was a bad algorithm. **Seven engines were
switched on, throwing no errors, and doing nothing.** An engine that is
enabled, silent, and saves 0% is indistinguishable from one that legitimately
did not apply — so 0% was read as "didn't fire here" for months.

| Engine | Defect | After |
| --- | --- | ---: |
| Token accounting | counted `len(text.split())` — whitespace words — as tokens | savings no longer over-reported |
| CompactTable | gate tested `"lossless"`; Rust emits `"lossless:table(…)"` | JSON 0% → **53.4%** |
| drain3 | read a dict as an object; also *destroyed* the 99.8% log path | **64.8%** |
| difftastic | side-by-side output was larger, so its own guard rejected 100% | **51.7%** |
| dedup | per-block copy loss | fixed, then reverted to opt-in on cache economics |
| context_budget | saw a 77k-token conversation as 12 tokens | **56.7%** |
| memoization / Kompress | no enable path existed at all | `--memoize`, `--enable-kompress` |

**When an engine reports 0%, assume it is unreachable until proven otherwise.**

## Measured, and where

- [`why-codex-saves-nothing.md`](why-codex-saves-nothing.md) — the largest

  content shape (code and patches).
- [`benchmarks-vs-llmlingua.md`](benchmarks-vs-llmlingua.md) — head-to-head at
  matched ratio against the published baseline. We lose on prose quality
  (0.332 vs 0.348 HotpotQA, 0.627 vs 0.757 LongBench) and win 150–500x on
  speed. Includes the metric bias that was found and fixed.
- [`reversible-code-compression.md`](reversible-code-compression.md) — 50.9%
  on source with four enforced contracts, off by default, with the economics

**Negative results are documented too** — BM25 ranking, stratified coverage,
budget-filled prose selection, lossless code normalisation (0.03%), and
Kompress-on-Codex-prose. Each cost a measurement cycle. Do not re-run them
without reading why they failed.

## Open decisions (not mine to make)

1. **Lead with routing, not compression.** The ledger says model routing
   created 136.9M tokens against compression's 28.9M — **4.7x** the feature all
   the material leads with. Positioning change, not a code change.
2. **`--enable-reversible-code` by default.** 50.9% on code, downside bounded
   at ~11%, prefix-stable, contracts tested. Off because code arrives via
   `Read`/`Grep`/`Bash`, which `DEFAULT_EXCLUDE_TOOLS` protects deliberately.
   One week of real traffic settles it — the query is in that doc.
3. **Which `graphify` package the product targets.** The code drives
   `python -m graphify.cli build --project-dir --output-dir`; the installed
   `graphify` has none of those flags. Availability now reports `unavailable`
   honestly rather than advertising a dead engine.

## Traps

Each of these produced a confidently wrong answer during this pass.

- **`cutctx_ai.pth` can point at a worktree.** It was aimed at
  `.worktrees/meta-harness-p0`, so every `cutctx` CLI call ran that tree while
  `python -c` from the repo root ran the right one (cwd wins on `sys.path`).
  Every CLI-based verification silently measured the wrong code. Check it
  first when a fix "does nothing".
- **CI pins `ruff==0.9.4`; a fresh install gets 0.14.x.** They disagree on
  rules (UP038) *and* formatting, and CI runs `ruff format --check .`. Verify
  with `uvx ruff@0.9.4 check . && uvx ruff@0.9.4 format --check .`.
- **Clear `.mypy_cache` before trusting a baseline** — a stale cache hid a real
  `str | None` error behind a bogus internal assertion.
- **Use `uv pip install`, not `uv sync`** — sync prunes conflicting extras and
  silently turns 64 passing tests into skips. `uv sync --all-extras` refuses by
  design.
- **`gh run rerun` is refused for several workflows here**, so a flaky
  Docker/registry job can only be retried by pushing a commit. And `cancelled`
  runs (superseded by a later push) read as failures unless filtered.
- **Synthetic corpora lie.** Kompress measured 6.8% on one sentence repeated
  200 times; real CodeSearchNet code falsified a contract that flat fixtures
  said was fine. Measure on real data before concluding.
- **Write a negative control for any new guard.** Two tests in this pass passed
  with the bug reintroduced. A test that cannot fail is not a test.
